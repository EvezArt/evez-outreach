# EVEZ Revenue Offers

These are the commercial offers the revenue engine should route prospects toward.

## 1. Workflow Audit

**Outcome:** a concrete automation map for one business workflow.

Includes:
- current-state workflow map
- automation opportunities
- integration requirements
- failure modes and verification points
- implementation plan
- estimated operating cost

**Starting price:** $250 fixed scope.

## 2. Automation Build

**Outcome:** one deployed workflow that can run repeatedly with logging and a handoff runbook.

Includes:
- workflow implementation
- agent/integration configuration
- verification and error handling
- deployment runbook
- measured acceptance criteria

**Price:** scoped after the audit.

## 3. Proof Runtime

**Outcome:** an evidence layer for AI workflows.

Tracks: `claimed -> observed -> executed -> verified`

Produces machine-readable evidence for important actions and separates verified outcomes from assumptions.

**Price:** scoped implementation.

## Sales rule

Never claim revenue, production status, customer count, performance, or deployment state without an observable record.

The commercial objective is:

`prospect -> audit -> build -> recurring support -> reusable product`

No invented traction. No fake metrics. No pretending a GitHub commit is a customer.
